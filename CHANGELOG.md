# Changelog

## v0.0.1 — First planned public release

- Moved all 22 parametric 3D tools into a single collapsible **ksaevelo's 3d presets/materials** section at the very bottom of Tools.
- Removed the experimental AE converter entirely from the panel.
- Standardized version `v0.0.1` in the user interface, manifest, and update-check logic.
- Consolidated duplicate stopwatch, clock, sticky-note and navigation handlers.
- Corrected 3D rig transforms to use After Effects scripting match-name properties; corrected 3D scale handling on footage layers.
- Preserved vector dimensions for several 3D layer animation utilities.
- Improved custom graph mapping and viewport control-point coordinates.
- Kept theme options, bundled presets, creator links and GitHub update notices.
